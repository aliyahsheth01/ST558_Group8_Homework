2. Long versus Wide Format Data

Long format data have one observation per row and one variable per column. Wide format data may contain more than one observation in a given row, with repeated measurements often spread across multiple columns.

For statistical analysis, long format data are generally preferred because most plotting, summarizing, and modeling methods expect data to be in long form.

  group_by(class) |>

    )
  )
