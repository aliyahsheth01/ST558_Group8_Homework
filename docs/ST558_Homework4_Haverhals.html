2.

When data is in “long” format, that means that every row represents an individual observation. “Wide” format allows for multiple observations to be in the same row. This seems like it’d be useful (or, at least, used) when collecting data longitudinally. It’s also good for displaying data.

It seems to me that we’d like to use long format data because it’d make it easier to pull call that data for the sake of manipulations. For example, if you have the same observation made over time, it’d be nice to have all those data in a single column when, say, finding the mean of them.
