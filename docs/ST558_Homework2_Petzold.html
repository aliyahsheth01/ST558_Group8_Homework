Task 4

1) Suppose we want to characterize the post-treatment (or placebo) blood pressure measurement as optimal (≤ 120), borderline (120 < bp ≤ 130), and high (> 130). First, create a new column in each data frame from above called status.

new_list[[1]]$status <- character(20)

new_list[[2]]$status <- character(10)

2) For the non-placebo data frame (within the list), create a for loop and use if/then/else logic to create the status column’s values

#looping through the full length of the status variable from the first element of the new_list list, which is the non-placebo data frame
for (i in length(new_list[[1]]$status)) {
  
  if (new_list[[1]]$post_bp[i] <= 120) {
    
    new_list[[1]]$status[i] = "Optimal"
    
  } else if (new_list[[1]]$post_bp[i] > 120 & new_list[[1]]$post_bp[i] <= 130) {
    
    new_list[[1]]$status[i] = "Borderline"
    
  } else if (new_list[[1]]$post_bp[i] > 130) {
    
    new_list[[1]]$status[i] = "High"
    
  }
  
}

3) Repeat for the placebo data frame (within the list).
