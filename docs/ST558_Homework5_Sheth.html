1. Connecting to News API

After obtaining the News API key from newsapi.org, the key was stored in an environment variable (“NEWSAPI_KEY”) through the local RStudio Console. The “httr” package is used to query the News API for recent articles related to pharmaceuticals. The search is limited to English-language articles published since September 1, 2026, and the returned API response is stored as an R object for further processing.

# Load package needed to query the API
library(httr)

# Retrieve NewsAPI key from the local RStudio console
news_api_key <- Sys.getenv("NEWSAPI_KEY")

# Query NewsAPI for recent pharmaceutical news

  paste0(
    "https://newsapi.org/v2/everything?q=pharmaceuticals",
    "&from=2026-09-01",
    "&language=en",
    "&apiKey=", news_api_key
  )
)

3. Create a Function to Query API

A function is created to allow a user to query the News API by specifying a search subject, a starting date, and an API key. The function sends the API request, parses the returned content, extracts the article information, and returns the results as a tibble. The function is demonstrated using two different search subjects.

# Create a function to query NewsAPI and return article information
query_news <- function(subject, from_date, api_key) {
  response <- GET(
    paste0(
      "https://newsapi.org/v2/everything?q=", subject,
    "&from=", from_date,
    "&language=en",
    "&apiKey=", api_key
    )
  )
response_content <- content(response)
article_list <- response_content$articles
for (i in seq_along(article_list)) {
  article_list[[i]]$source <- list(article_list[[i]]$source)
}
article_data <- dplyr::bind_rows(article_list)
return(article_data)
}
